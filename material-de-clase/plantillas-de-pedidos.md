# Plantillas de pedidos

Copia una plantilla, cambia lo que está entre [CORCHETES] y pégala en Claude Code o Codex.
Cuanto más concreto seas, menos vueltas tendrás que dar.

---

## 1. Primer video (briefing completo)

```
/editar-video
Video: [ARRASTRA AQUÍ EL ARCHIVO]
Red: [Reels / TikTok / Shorts / YouTube / anuncio]
Objetivo: que quien lo vea [ENTIENDA / HAGA] [QUÉ COSA].
Público: [QUIÉN LO VA A VER].
Estilo: [serio / enérgico / elegante / divertido]. Ritmo [natural / rápido tipo TikTok].
Subtítulos: palabra resaltada en [COLOR], [más grandes / normales].
Animaciones: título con el gancho al inicio, zoom en las frases fuertes y [emojis sí/no].
Llamado a la acción: "[TEXTO EXACTO QUE DICES AL FINAL]".
No cambies lo que digo ni inventes cifras. Muéstrame primero una muestra de 8 segundos.
```

## 2. Usar otro video como referencia

```
Mira cómo está editado este video de referencia: [DESCRÍBELO o pega el enlace].
Lo que me gusta: [ritmo / tipo de subtítulos / títulos / zooms / emojis].
Aplica ese estilo a mi video con MIS colores y MI mensaje. No copies sus textos ni su marca.
Propónme primero la lista de efectos (frase → efecto) antes de aplicarlos.
```

## 3. Corregir un trozo concreto (sin tocar lo demás)

```
Entre el segundo [INICIO] y el [FIN] pasa esto: [DESCRIBE EL PROBLEMA].
Quiero que quede así: [RESULTADO QUE SE PUEDA COMPROBAR].
No toques: [cortes / subtítulos / animaciones / el resto del video].
Enséñame solo ese trozo con una muestra.
```

Ejemplos de "resultado que se pueda comprobar":
- "El subtítulo no tapa la barbilla".
- "El título aparece justo cuando digo 'tres errores'".
- "No se corta la palabra 'dinero' al final".

## 4. Cuando el mismo error se repite

```
Esto ya lo intentamos y sigue fallando: [PROBLEMA].
Antes de cambiar nada, explícame por qué pasa y qué vas a probar.
Prueba una sola cosa y enséñame el resultado.
```

## 5. Guardar tu estilo para los próximos videos

```
Me gusta cómo quedó este video. Guarda este estilo en mi marca (/marca):
colores, tamaño y posición de subtítulos, sonidos y música.
Para el próximo video, aplícalo igual y solo adapta las animaciones a lo que digo.
```

## 6. Varias versiones para testear (anuncios)

```
Hazme [2/3] versiones de este video que solo cambien [el título del inicio / el primer
segundo / el emoji del gancho]. Todo lo demás igual. Nómbralas A, B y C y apunta en
material-de-clase/matriz-de-variaciones.csv qué cambia en cada una.
```

---

**Consejo:** pide siempre una **muestra de 8 segundos** antes del video completo.
Revisarla en el móvil con sonido ahorra tiempo y uso del plan.
