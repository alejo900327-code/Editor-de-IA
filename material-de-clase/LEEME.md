# Material de clase

| Archivo | Para qué |
|---|---|
| `plantillas-de-pedidos.md` | Pedidos listos para copiar: primer video, referencia, correcciones, estilo y variaciones |
| `guiones-de-practica.md` | 3 guiones para grabar y practicar la edición en clase |
| `registro-de-revisiones.csv` | Anota cada corrección (qué falla, cómo debe quedar, qué no se toca) |
| `control-de-costos.csv` | Calcula cuánto te cuesta cada video (herramientas y tu tiempo) |
| `matriz-de-variaciones.csv` | Organiza versiones A/B/C de un anuncio y sus resultados |

Los `.csv` se abren con Excel, Google Sheets o Numbers. Usan `;` como separador; si en tu
programa salen en una sola columna, impórtalos eligiendo "punto y coma".
